# C1: Physics Realism Prompts

## What It Covers

Images requiring precise physical accuracy — correct time displays, realistic materials, proper physics, accurate measurements, and real-world consistency.

## Key Techniques

### 1. Exact Values

Specify exact numbers when precision matters:
- Time: "showing exactly 11:15", "timestamp October 1st 2018"
- Measurements: "filled exactly to the rim"
- Counts: "with correct tick marks"

### 2. Material & Physics Descriptors

Describe physical properties that force realism:
- Liquids: "realistic meniscus", "natural reflections", "no spill"
- Solids: "polished gold chain", "crystal wine glass"
- Light: "soft daylight", "natural lighting"

### 3. Real-World Reference

Anchor to real objects/scenes:
- "the breed of dog which biden had as a pet"
- "Northrop Grumman B-2 Spirit stealth bomber"

## Prompt Templates

### Precise Object/Scene
```
[Setting description]. [Object 1] showing exactly [precise detail]. [Object 2] with [physical property]. [Lighting], [camera detail].
```

### Real-World Entity
```
[Real entity description] [performing action] with [specific prop showing precise detail]. [Environment context].
```

### Physical Phenomenon
```
[Scene]. [Object] demonstrating [physical behavior]. [Material details]. [Lighting revealing physical property]. Realistic [material type], [camera specification].
```

## Example Prompts

**Precise Time + Object Physics:**
```
A cozy dining table scene. On the wall, a clock showing exactly 11:15 with correct tick marks. A crystal wine glass on the table is filled exactly to the rim with liquid—no spill, realistic meniscus, and natural reflections. Soft daylight, 50mm lens look.
```

**Real-World Knowledge + Physics:**
```
the breed of dog which biden had as a pet holding up a newspaper with the top headline from october 1st 2018 on a skateboard.
```

**Product Physics (with reference):**
```
A photorealistic close-up of a gold pendant necklace held by female hand. The pendant features a bas-relief engraving of [image /emoji]. The pendant hangs from a polished gold chain. The background is softly blurred with neutral beige tones, and natural lighting, realistic skin tones, Product photography, 16:9 aspect ratio.
```

## Tips

- Use words like "exactly", "precise", "realistic" to reinforce accuracy
- Describe what NOT to show when relevant ("no spill", "no distortion")
- Include camera terminology for photorealistic results
- For product shots, specify "Product photography" as a style keyword
- Real-world knowledge prompts work — the model knows public figures, landmarks, etc.

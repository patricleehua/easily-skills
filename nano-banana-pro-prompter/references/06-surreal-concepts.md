# C6: Surreal Concepts Prompts

## What It Covers

Impossible, dreamlike, or creatively mashed-up scenes — objects made of unexpected materials, absurd combinations, dreamscapes, and conceptual art that defies physical rules.

## Key Techniques

### 1. Simple Direct Statements

Surreal concepts often work best with short, direct prompts:
```
A motorbike made of sharks
```
```
A man drinking bottle of sushi water and looking at beautiful-shaped skies, smirking
```

### 2. "Made of" / "Constructed from"

A powerful pattern for impossible objects:
```
A [vehicle/object] made of [unexpected material/creature]
```

### 3. Unexpected Combinations

Combine unrelated concepts:
- Animal + vehicle: "whippet riding a moped"
- Object + impossible physics: "sun exploding into pigeons"
- Scale reversal: "tiny human inside an acoustic guitar"
- Role reversal: "duck, chicken and parrot riding a scooter"

### 4. Absurd Scenarios

Describe impossible but visually vivid scenarios:
```
An old lady balancing sumo wrestlers on the Statue of Liberty
```

## Prompt Templates

### Impossible Object
```
A [object] made of [impossible material/elements]. [Additional visual details]. [Style/lighting].
```

### Absurd Scenario
```
[Subject A] [unexpected action] [Subject B] in [setting]. [Additional surreal details]. [Mood/atmosphere].
```

### Dreamscape
```
[Surreal scene description]. [Impossible physics/behavior]. [Ethereal/dreamlike quality]. [Color palette], [atmosphere].
```

### Concept Mashup
```
[Concept A] meets [Concept B]. [Scene combining elements of both]. [Style treatment], [visual mood].
```

## Example Prompts

**Impossible Object:**
```
A motorbike made of sharks
```

**Absurd Scenario:**
```
An old lady balancing sumo wrestlers on the Statue of Liberty
```

**Dreamscape:**
```
The sun exploding into a flock of pigeons. Brilliant orange and red light scattering through feathers. Birds silhouetted against the expanding solar corona. Surreal cosmic photography.
```

**Creative Mashup:**
```
A man drinking bottle of sushi water and looking at beautiful-shaped skies, smirking
```

**Scale Reversal:**
```
A tiny human explorer standing inside an acoustic guitar. The strings form a massive harp-like structure above. Warm wood tones, dust particles floating in shafts of light. Macro photography perspective.
```

**Volcanic Pattern:**
```
Volcanic werewolf camouflage pattern. Fur texture blending with flowing lava, dark basalt, and glowing magma veins. Repeating seamless pattern design. Fiery reds, deep blacks, molten orange.
```

## Tips

- Short and direct often works better than over-explaining for surreal concepts
- Let the model fill in visual details — don't constrain creativity too much
- "Surreal", "impossible", "dreamlike" as keywords help set the tone
- Absurd humor translates well: "whippet with an eye patch riding a moped"
- Color and mood words help guide the atmosphere even when content is wild
- For pattern/texture prompts, specify "seamless pattern", "repeating design"

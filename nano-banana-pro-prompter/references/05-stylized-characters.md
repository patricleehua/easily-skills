# C5: Stylized Characters Prompts

## What It Covers

Character design and rendering in non-photorealistic styles — 3D models, chibi, anime, game sprites, Funko Pop, figurines, plush toys, and stylized illustrations.

## Key Techniques

### 1. Specify the Render Style

Be explicit about the visual style:
- "3D character model"
- "Chibi Funko Pop 3D character render"
- "Realistic 1/7 scale figure"
- "Pixel art sprite sheet"
- "Ghibli-style illustration"
- "Knitted yarn doll"
- "Gashapon capsule diorama"

### 2. Define Visual Qualities

Describe the aesthetic properties:
- Colors: "crisp, defined, and bold colors", "pastel palette"
- Surface: "glossy finish", "matte plastic", "plush fabric texture"
- Edges: "cel-shaded", "clean outlines", "soft edges"
- Rendering: "unreal engine style", "octane render", "blender 3D"

### 3. Character Details

For character-focused prompts:
- Body proportions: "big-headed", "chibi proportions", "tall and muscular"
- Expression: "playful expressions", "mischievous smile", "stoic"
- Pose: "dynamic action pose", "standing idle", "sitting on desk"
- Outfit: describe clothing and accessories precisely

### 4. Context/Display

Where the character is displayed affects the render:
- "on a desk" — figure/diorama display
- "white background" — character sheet
- "in [environment]" — scene integration
- "sprite sheet format" — game asset

## Prompt Templates

### 3D Character Model
```
3D character model of [character]. The style should be [style description], with [color/surface quality]. [Character appearance details]. [Pose/expression]. [Background/display context].
```

### Figure/Diorama
```
Realistic 1/7 scale [character type] figure on [display surface]. [Figure details: sculpting, paint, materials]. [Display context: desk, shelf, with props]. [Lighting], [camera angle].
```

### Anime/Chibi
```
[Style] illustration of [character]. [Proportions]. [Clothing/accessories]. [Expression/pose]. [Color palette]. [Background]. [Additional style modifiers].
```

### Game Sprite/Asset
```
[Game era/style] sprite sheet of [character]. [Number of poses/frames]. [Art style: 16-bit, pixel art, etc.]. [Character design details]. [Transparent/grid background].
```

## Example Prompts

**Stylized 3D Character:**
```
3D character model of a zombie. The style should be stylized and graphic, with crisp, defined, and bold colors. The zombie should have a gloomy inspired aesthetic only wearing torn shorts. Has decaying flesh.
```

**Chibi Figure:**
```
Chibi Funko Pop 3D character render of [character name]. Big head with large expressive eyes, small body. [Outfit description]. Glossy vinyl finish, displayed on white surface. Soft studio lighting, product photography style.
```

**Scale Figure:**
```
Realistic 1/7 scale figure of [character] on desk with ZBrush display. Detailed sculpting, hand-painted finish. [Character pose and outfit]. Desk has [accessories: monitor, keyboard, small props]. Studio lighting, close-up photography.
```

**Knitted/Craft:**
```
Hand-crocheted yarn doll of [character], cradled in gentle hands. Soft pastel yarn colors, visible knit texture, button eyes, rosy cheeks. Warm close-up photography, shallow depth of field, cozy natural lighting.
```

**Gashapon Diorama:**
```
Gashapon capsule diorama of [NAME] in [iconic pose/style]. Miniature figure inside clear plastic capsule, [character details]. Colorful candy-toy aesthetic, tiny props and base. Macro photography, shallow depth of field.
```

## Tips

- "Product photography" combined with figure descriptions creates realistic product shots
- Specify the exact medium: "vinyl", "resin", "plush", "crocheted yarn" for material accuracy
- For anime styles, mention specific aesthetics: "Ghibli", "shonen", "chibi SD"
- Sprite sheets benefit from: "multiple poses", "walk cycle", "8-directional"
- "Cel-shaded" gives anime-style 3D rendering
- Scale descriptions help: "1/7 scale", "miniature", "life-size"

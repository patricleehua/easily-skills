# Hyperliquid Trading CLI 测试计划

> **测试环境**: Hyperliquid Testnet (测试网)
> **测试目标**: 验证 SKILL.md 中所有命令功能正常，技能文档描述准确

---

## 前置准备

```bash
# 1. 进入项目目录
cd hyperliquid-trading

# 2. 安装依赖
uv sync

# 3. 安装 hyperliquid-trading
uv pip install -e .

# 4. 配置测试网环境 (确保 .env 中 HL_NETWORK=testnet)
# 需要提前准备测试网钱包地址和私钥
```

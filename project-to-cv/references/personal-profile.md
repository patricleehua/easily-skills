This profile is an interview-confidence reference only. It must not override the analyzed project's real technology stack. If the project is Go, Python, Node.js, frontend, data, infrastructure, or AI workflow, write that project using its actual stack first. Do not default to Java unless the project evidence or user request requires Java positioning.
